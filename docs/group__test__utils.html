Сравнивает два набора сигналов по размеру, диапазону и значениям.

Аргументы
expectedИсходные данные (из .bin).
actualСравниваемые данные (из parquet/duckdb/hdf5).
labelНазвание источника.
Возвращает
true Если данные полностью совпадают.
false Если найдено несоответствие.

Последовательность работы:

  1. Сравнивает num_points и num_channels.
  2. Сравнивает ifirst_point/ilast_point.
  3. Поэлементно сравнивает значения всех каналов.
  4. При ошибке выводит сообщение и возвращает false.

Проверяет корректность чтения чанков в случайном порядке.

Аргументы
read_signalФункция чтения диапазона.
source_pathПуть к файлу для чтения данных.
referenceДанные для проверки.
chunk_pointsРазмер чанка.
Возвращает
true Если все случайные чанки совпали с исходными.
false Если обнаружено несовпадение размеров или значений.
Исключения
Любыеисключения, которые бросает read_signal, а также возможные исключения выделения памяти.

Последовательность работы:

  1. Формирует и перемешивает порядок индексов чанков.

  4. При первой ошибке возвращает false.
