Потоково читает диапазон точек из DuckDB через соединение.

Аргументы
connОткрытое DuckDB-соединение.
dataВыходная структура SignalData.
point_offСмещение от начала диапазона.
point_cntКоличество точек для чтения; если < 0, читается доступный диапазон.
Исключения
std::invalid_argumentЕсли point_off отрицательный.
std::runtime_errorПри ошибках SQL, несогласованности схемы, несовпадении объёма чтения или недопустимом LSB.

Последовательность работы:

  1. Валидирует входные параметры.
  2. Читает метаданные и подготавливает окно чтения.
  3. Готовит SELECT по id BETWEEN ? AND ?.
  4. Потоково читает chunks и конвертирует int32 в double.
  5. Проверяет, что прочитано ровно ожидаемое число точек.

Потоково записывает диапазон точек в DuckDB через filepath с периодическими commit.

Аргументы
bin_pathПуть к .hdr/.bin источнику.
duckdb_pathПуть к DuckDB-файлу назначения.
point_offСмещение от начала диапазона.
point_cntКоличество точек для чтения; если < 0, читается доступный диапазон.
chunk_pointsРазмер чтения/записи чанка в точках.
commit_every_n_pointsКоличество точек между промежуточными commit.
Исключения
std::invalid_argumentЕсли chunk_points <= 0 или point_off < 0.
std::runtime_errorПри ошибках чтения BIN, транзакций, appender-а или подключения DuckDB.

Последовательность работы:

  1. Открывает .bin и DuckDB (с попыткой задать лимит памяти).
  2. Создаёт схему и записывает метаданные сигнала.
  3. Запускает транзакцию и appender для таблицы points.
  4. Читает BIN чанками и вставляет строки.
  5. При достижении порога commit_every_n_points делает commit и открывает новую транзакцию.
  6. Выполняет финальный commit и закрывает ресурсы.
